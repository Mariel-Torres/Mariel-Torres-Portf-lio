# Portfólio — Mariel Torres

Portfólio estático desenvolvido com **HTML, CSS e JavaScript puro**, pronto para publicar no GitHub Pages.

## Estrutura

- `index.html` — conteúdo e estrutura das secções
- `styles.css` — layout, cores, responsividade e animações
- `script.js` — menu mobile e ano automático no rodapé

## Como executar localmente

Basta abrir `index.html` no navegador. Para uma experiência melhor durante o desenvolvimento, podes usar a extensão **Live Server** no VS Code.

## Publicar no GitHub Pages

1. Cria um repositório no GitHub, por exemplo `mariel-portfolio`.
2. Extrai os ficheiros deste ZIP.
3. Envia `index.html`, `styles.css`, `script.js` e este `README.md` para a raiz do repositório.
4. No GitHub, abre **Settings → Pages**.
5. Em **Build and deployment**, escolhe **Deploy from a branch**.
6. Seleciona a branch `main` e a pasta `/ (root)`, depois carrega em **Save**.
7. Aguarda a publicação. O GitHub mostrará o endereço do site na mesma página.

## Antes de publicar

- Os três projetos são **demonstrações visuais/conceitos** incluídos para dar estrutura ao portfólio. Não os apresentes como trabalhos comerciais concluídos se ainda não os desenvolveste.
- Substitui os projetos de demonstração por projetos teus e adiciona os respetivos links de GitHub e demonstrações online.
- Confirma os dados de contacto e atualiza o link do GitHub se necessário.
- O link do LinkedIn não foi incluído porque o endereço anteriormente fornecido parecia incompleto.
